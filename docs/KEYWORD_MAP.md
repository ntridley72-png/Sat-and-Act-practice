# Keyword and search-intent map — November 2026

**No search volumes or difficulty scores appear here, because none were measured.** Search engines' autocomplete
endpoints (Google, Bing, DuckDuckGo) are blocked from the build environment, and no Search Console data exists yet.
This map is built from three things that can be checked: what pages FunSAT already has, which competitor URLs rank in
public search results for these intents, and what searchers ask for in public forums. Replace the "Likely competition"
column with real impressions and positions from Search Console four to six weeks after the site is verified.

## How to read the priority

Priority uses the 100-point framework from the brief, scored by judgement: student usefulness 25, organic potential 25,
retention 15, differentiation 15, evidence 10, feasibility 10. Organic potential is a guess until Search Console data exists.
