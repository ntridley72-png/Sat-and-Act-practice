# Pre-change audit — 2026-10-07

Repository inventory: 235 tracked files, including 102 PNGs, 25 HTML files, 29 JS files, 20 CJS files (19 existing test scripts), Python generators, fonts and vendored Three.js. All tracked text was scanned for advertising/analytics integration points; application managers, templates, generators, deployment, account API and tests were inspected. Question/college datasets and vendor code are preserved.

Architecture: vanilla JS SPA in `SAT & ACT Practice.html` + 1 MB `app.js`; no frontend package/build framework. `workspace.js`, `redesign.js` and CSS enhance it. Cloudflare Worker serves static assets and authenticated D1 progress/tutor APIs. Python builds substantive guides, college/scholarship data pages, landing pages and sitemaps. SEO canonical redirects, structured data, fonts and cache revalidation already work.

SAT: start/test/routing/results states; adaptive module selection, score estimates, ACT conversion, domain breakdown, weakest-domain drills, predictor/history, explanations and answer review already exist. No separate break state exists; do not invent one for ads. Account persistence, local data and scoring must stay unchanged.

Games: shared fixed full-viewport overlay, canvas scaled to viewport, keyboard/touch/D-pad, credits and natural ready/playing/paused/over/timeup states. Existing round-based runs cap at five minutes; do not promise 60-minute uninterrupted runs or change credits for monetization. Rails must not resize canvas to make room.

Existing ads: `ads.js` supports direct, AdSense and active Adsterra. Main HTML and `seo_common.py` hard-code Adsterra bauval.org scripts; native container migrates between slots, duplicate skyscraper units and square grids exist. Global rails are fixed at 1420px, not aware of game/control geometry. Custom anchor code exists. `setPracticeMode` forcibly hides Google ads including vignettes and a broad DOM observer repeats that operation. Privacy text incorrectly describes active Adsterra as child-directed AdSense. ads.txt lists no authorized sellers.

Analytics: no GA/gtag or product-event collector found; local attempt history is product storage, not aggregate analytics. No owner/admin dashboard or admin authorization exists. Do not introduce an insecure admin route; provide a local modeling artifact instead. Credentials are Worker env bindings; no committed AdSense publisher ID found.

Plan: one fail-closed, consent-gated AdSense manager; Worker-provided public configuration; one-shot visible-unit requests and explicit reservations; remove Adsterra, grid stacking and custom anchors. Auto Ads enabled in Google's dashboard on content pages, with the interactive root URL excluded before enabling manual SPA slots. Never modify Google-generated elements. Existing results enhanced with difficulty evidence and review filtering, no extra artificial routes. Optional document-flow game rails only where measured game AND control spacing permits. Product events sent only through an explicitly consented analytics adapter; revenue stays in official reporting. Add meaningful policy/failure/geometry tests and a reviewable operator runbook.
